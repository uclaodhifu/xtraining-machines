# X Training 器械照片 → 识别模型

往 `照片/器械名/` 里传照片，传完会自动在云端训练，几分钟后 `模型/` 里出现新模型和准确率报告。

## 怎么传（手机上）

1. 用浏览器打开本仓库，点进 `照片`，再点进对应器械的文件夹（比如 `高位下拉`）
2. 右上角 **Add file → Upload files**，选照片，点最下面绿色的 **Commit changes**
3. 没有的器械：在 `照片` 里 **Add file → Upload files**，上传前把文件名前面加上 `新器械名/`（比如 `腿举V字/1.jpg`），就会新建文件夹

也可以直接把照片发给 Claude，说是什么器械，Claude 帮你放好。

## 怎么拍更好

- 拍**整台器械**，前、侧、斜着各一张，有人坐着、没人都行
- 每种器械至少 **20 张**，不同健身房、不同牌子越多越准
- 文件夹名就是识别出来的名字，同一种器械别分两个文件夹

## 现在有什么

- `公开-*.jpg`：free-exercise-db 的健身房实拍（公有领域，可自由使用）
- `我拍-*.jpg`：自己拍的
- 每次训练的结果在 `模型/准确率报告.txt`
